# Customized 3D Fashion Design and Order Management System

An e-commerce platform for 7 Guys House of Fashion, featuring an interactive 3D environment for custom clothing design.

This project was originally built with Laravel ([legacy version](https://github.com/Izlaw/capstone-project-legacy)). After graduation I chose to completely rebuild it from scratch in C# and Blazor WebAssembly to challenge myself.

**Stack:** C# | Blazor WebAssembly (.NET 9) | MudBlazor | Three.js | Supabase

## Disclaimer

7 Guys House of Fashion is a real, legitimate business, but this website is just a student capstone project and is not the official website of 7 Guys House of Fashion. Any orders, designs, or accounts made here are for demonstration purposes only and will not be processed by the business.

The project was originally built in PHP/Laravel and has since been rebuilt from the ground up in C#/Blazor, both as a personal challenge and as an improvement on the legacy version.

Please avoid entering any sensitive personal information while using this site.
