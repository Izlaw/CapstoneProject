# Customized 3D Fashion Design and Order Management System

An e-commerce platform for 7 Guys House of Fashion, featuring an interactive 3D environment for custom clothing design.

This project was originally built with Laravel ([legacy version](https://github.com/Izlaw/capstone-project-legacy)). After graduation I chose to completely rebuild it from scratch in C# and Blazor WebAssembly to challenge myself.

**Stack:** C# | Blazor WebAssembly (.NET 9) | MudBlazor | Three.js | Supabase
